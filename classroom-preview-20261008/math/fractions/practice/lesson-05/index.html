Equivalent Fractions with Fraction Strips

ML 1.05 • Same whole + same endpoint = same value.

Two Worked Examples

Look at where each shaded length ends. The strips must represent the same whole.

Example 1

1/2 and 3/6 have the same endpoint.

Different names, same length.

Example 2

1/4, 2/8, and 3/12 all end at the same place.

One fraction can have more than one equivalent name.
