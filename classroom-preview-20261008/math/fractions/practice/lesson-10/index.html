ML 1.10 — Identifying Equivalent Fractions Using Multiplication and Division

Generate and identify equivalent fractions using both multiplication and division.

Worked Example

Start with 12/8.

Multiply both terms by 2: 24/16.

Divide both terms by 4: 3/2.

Both results are equivalent to 12/8 because the same factor was used on the numerator and denominator.

Key takeaway: Multiplication can always generate a larger equivalent fraction. Division works when the numerator and denominator share a common factor.
