ML 1.07 — Equivalent Fractions on a Number Line

Find and generate equivalent fractions by matching the same location on differently partitioned number lines.

Worked Example

1/2 and 2/4 are equivalent because both land at the same location halfway between 0 and 1. The denominators change the number of equal spaces; the point’s location does not change.
